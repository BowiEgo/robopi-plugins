# 002 知识库优先检索：四层强制链

> 状态：设计（未实施）| 2026-08-31
> 相关：003-qa-area.md（问答区域如何展示这些过程）

## 1. 问题本质

"优先查知识库"包含两个诉求：**时机**（回答前必须先检索）与**门控**（有结果用库、无结果才放行其他来源）。
仅靠提示词不可靠；可靠度排序：强制注入 > 工具强制首调 > 路由 > 提示词。

## 2. 业界通用方案对比

| 方案 | 机制 | 可靠性 | 缺点 |
|---|---|---|---|
| 强制 RAG 注入 | 每次提问自动检索并直接注入上下文 | ★★★★★ | 无关问题也检索（需阈值） |
| 工具强制首调 | tool_choice 强制第一轮调 kb 工具 | ★★★★ | 依赖框架支持；多轮强制烦 |
| RAG 路由 | 独立路由层判定是否知识库问题 | ★★★☆ | 路由误判成本 |
| 工具 + 提示词 | kb 工具排最前 + 指令 | ★★☆ | 模型可违背 |
| 纯提示词 | 仅指令 | ★ | 最不可靠 |

## 3. 本项目可用的 pi 扩展钩子（已核实）

| 钩子 | 时机 | 用途 |
|---|---|---|
| `input`（可 transform 改写文本） | 用户输入到达、agent 处理前 | 强制 RAG 注入点 A |
| `before_agent_start` | agent 开始前 | 注入点 B（指令 + 检索摘要） |
| `context` | 上下文构建时 | 注入检索结果（更干净） |
| `tool_call`（可拦截/改写，含 CustomToolCallEvent） | 工具执行前 | 改写 kb query、检索日志、无结果门控 |
| `registerTool` | 会话启动 | 注册 `search_knowledge_base` 工具 |

## 4. 四层强制链（推荐设计）

```
用户提问
  ├─ ① 意图路由（轻量）：领域词典/关键词（产品名/部门/项目代号/文档标题前缀）
  │      命中 → 标记"企业知识类问题"；未命中 → 也走检索（阈值更严）
  ├─ ② 强制 RAG 注入（input/context 钩子）：
  │      自动执行 search_knowledge_base(query)
  │      Top-k 分块 + 来源路径 + 置信分 注入上下文
  │      指令："以上为知识库检索结果，优先据此回答并引用来源"
  ├─ ③ 工具可用（registerTool "search_knowledge_base"）：
  │      模型可二次检索（追问/多轮过滤）；描述注明"企业权威来源，优先使用"
  ├─ ④ 无结果门控（tool_call 钩子 + 注入内容）：
  │      空/低分 → 注入"知识库无相关结果，可转用其他来源"
  └─ 评估闭环：每次检索记录（query/命中/来源/耗时/是否被引用）
         → 供"评估与优化"模块分析
```

## 5. 关键设计决策

- **检索与 UI 共享数据层**：检索工具为服务端 Cordis 插件（`@core/kb-search`），直接读 `~/.pi/agent/robopi/data/knowledge-base/`；浏览器插件只做编辑/展示。数据一个源，检索即时生效，无网络 API。
- **强制注入代价控制**：置信阈值过滤低相关结果，避免无关噪声（省 token）。
- **会话级策略**：参考 tool-presets 思路，"知识库模式"预设控制强制注入开关。

## 6. 与"上网查询"的关系（企业场景）

- kb 工具永远排在 web 工具前；提示注明"知识库是企业权威来源"；
- **默认不启用 web 工具**（隐私 + 质量）；启用时仅知识库无结果才被允许（门控层保证）；
- 回答要求**引用来源**（返回文档路径），可审计。

## 7. 实施前需验证

1. `context` 事件 `ContextEventResult` 是否支持追加内容（支持则优先用它而非改 input 文本）；
2. pi SDK 是否暴露 `tool_choice`/强制首调参数（有则加一层保险）；
3. 检索质量：一期关键词/全文检索（参考宿主 file-fuzzy），二期语义检索（embedding）；
4. 多轮对话：检索注入去重/时效控制。

## 8. 实施分层

| 阶段 | 内容 |
|---|---|
| 一期 | @core/kb-search（数据层 + 关键词检索 + registerTool）+ pi 扩展注入（input/context）+ 门控 + 检索日志 |
| 二期 | 意图路由词典（可配置）+ 置信阈值调优 + 引用溯源渲染 |
| 三期 | 语义检索（embedding）+ 评估闭环可视化 |
